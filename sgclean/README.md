# 🛍️ ShopGenie AI

> **Shop smarter. Compare better. Buy with confidence.**

ShopGenie AI is an intelligent shopping assistant that understands natural-language requests and helps users discover, compare, shortlist, and purchase products through a guided AI-powered experience.

## ✨ What makes ShopGenie different?

Just tell Genie what you need:

> “Find me a lightweight laptop for coding and gaming under ₹80,000.”

ShopGenie turns that request into a smarter shopping journey:

**Discovery → Recommendations → Comparison → Cart → Checkout → Order Tracking**

## 🚀 Features

- 🤖 **AI Shopping Agent** — Natural-language product discovery
- 🔎 **Smart Search** — Search by budget, features, category, and preferences
- 🧠 **AI Recommendations** — Understand why products match your needs
- ⚖️ **Product Comparison** — Compare relevant specifications
- ❤️ **My Shortlist** — Save products for later
- 🔔 **Price Alerts** — Set target prices
- 🛒 **Smart Cart** — Manage products and quantities
- 💳 **Guided Checkout** — Clear review before purchase
- 📦 **Orders & Tracking** — Manage and track purchases
- 🌗 **Light / Dark Mode** — Choose your preferred theme
- 📱 **Responsive Design** — Works across devices

## ⚙️ Run Locally

```bash
git clone <your-repository-url>
cd shopgenie-ai
npm install
```

Create `.env.local`:

```env
GEMINI_API_KEY=your_api_key_here
```

Start the app:

```bash
npm run dev
```

Open `http://localhost:3000`.

## 🔐 Security

Never commit your Gemini API key or `.env.local` to GitHub.
